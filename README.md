# Agents Rurals · Estudi

App d'estudi (PWA) per a l'oposició d'agent rural: temari i banc de preguntes.

Obre-la a https://ismael-depedro-embid.github.io/agents-rurals/ i instal·la-la des del navegador
(Android/Chrome: «Instal·lar aplicació»; iPhone/Safari: Compartir → «Afegir a la pantalla d'inici»).
Funciona sense connexió un cop carregada.

Has trobat un error en una pregunta? Fes servir el botó «Reportar un error» de l'app, que obre
una incidència en aquest repositori amb la pregunta ja emplenada.

Aquest repositori conté només l'app construïda; es genera automàticament.
